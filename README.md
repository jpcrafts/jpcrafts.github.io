# Joshua P. Crafts — research portfolio

A personal academic portfolio for experimental nuclear physics, featuring NPS neutral-pion analysis, calorimeter development, selected publications, and scientific software.

The site is built with plain HTML, CSS, and a small JavaScript file. No dependencies or build step are required. Open `index.html` directly to preview it.

## Website

[jpcrafts.github.io](https://jpcrafts.github.io/) will work once the repository is published and GitHub Pages deploys.

## Files

- `index.html` — portfolio
- `styles.css` — responsive styles
- `script.js` — mobile navigation and publication filters
- `cv.html` — printable academic CV
- `assets/joshua-crafts-at-work.png` — owner-supplied laboratory photograph
- `assets/favicon.svg` — site icon
- `.nojekyll` — serve the static files directly

## GitHub Pages

Publish these website files at the root of `jpcrafts/jpcrafts.github.io`. In repository **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**.

Keep the original resume, private notes, and QA screenshots out of the public repository. The printable CV intentionally omits the street address, phone number, and email pending the owner's contact preferences.

## Editing

Update research, publications, and experience directly in the HTML files. Keep `index.html` and `cv.html` consistent. Publication links point to journal DOIs and public laboratory records. The introductory photograph was supplied by Joshua P. Crafts for this portfolio.
